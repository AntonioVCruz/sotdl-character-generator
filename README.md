# SotDL Character Generator

Gerador de personagens para *Shadow of the Demon Lord* (Schwalb Entertainment), pensado para jogadores e mestres em geral, inclusive quem ainda não domina as regras. Projeto pessoal e não comercial.

## Estado

**Planejamento.** O projeto segue Spec-Driven Development. Ainda não há código: os artefatos de especificação estão sendo produzidos a partir dos princípios de design e do wireframe.

## Estrutura

```
docs/
  reference/   Insumos já definidos: princípios de design, wireframe,
               ficha final e lições da tentativa anterior.
  ...          Artefatos de especificação (requisitos, UX, arquitetura,
               plano), gerados durante o planejamento.
content/       Conteúdo extraído dos livros. Somente local: fica fora
               do controle de versão.
```

## Conteúdo dos livros

Este repositório é público e **não contém texto, tabelas ou arte dos livros** de *Shadow of the Demon Lord*. O conteúdo extraído fica na pasta `content/`, que o `.gitignore` mantém fora do Git. Não copie trechos dos livros para nenhuma outra pasta do repositório.

*Shadow of the Demon Lord* é marca da Schwalb Entertainment. Este projeto não é afiliado nem endossado pela editora.
